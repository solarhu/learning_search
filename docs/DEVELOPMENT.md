## 构建说明

### 前端 Flutter Web

```bash
flutter pub get
flutter build web --release
```

### 后端 Go

```bash
cd server
go build -o server main.go
./server
```

### 运行后端（开发模式）

```bash
# 需要设置 OPENAI_API_KEY 环境变量
export OPENAI_API_KEY=your-key-here
cd server && ./server
```

## Git 分支规则

- `master`: 稳定主线，接受 PR 合并
- `dev`: 当前开发分支，所有新开发在这里进行
- 功能开发: 从 `dev` 拉出特性分支，开发完成后 PR 合入 `dev`，测试后再合入 `master`

## 交互设计要点

1. **自定义标注流程**
   - 搜索模式：长按文本 → 弹出对话框 → 输入关键词 + 标注说明 → 获取解释 → 存入会话
   - 学习模式：长按文档 → 弹出对话框 → 输入关键词 + 标注说明 → 获取解释 → 存入会话
   - 重新生成文档时，所有自定义解释会自动整合进去

2. **导出功能**
   - 后端生成文件（PDF/Markdown），返回二进制
   - Flutter Web 使用 `dart:html` AnchorElement 触发浏览器下载

## 关键点

- MVP 阶段不做后端持久化，所有状态由前端维护
- 利用 LLM 能力直接生成关键词/文档，减少后端代码复杂度
- 采用 Flutter 全跨端，代码共享率 > 90%
- OpenAI 兼容接口，可以轻松切换到其他兼容模型
