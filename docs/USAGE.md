# 使用文档

> 递进式学习搜索工具 - 使用指南

## 简介

**递进式学习搜索** 是一款帮助用户**循序渐进学习新知识**的工具：

1. 你提问 → 得到核心简明答案
2. 点击自动提取的关键词，逐步深入理解
3. 遇到你想深入了解的自定义内容，可以**长按添加自定义标注**
4. 所有知识点解释完毕，一键生成**完整结构化学习文档 + 思维导图**
5. 导出 Markdown / PDF 保存学习成果

支持 **Web 网页** 和 **鸿蒙OS 手机App** 双端。

---

## 启动服务端

### 1. 编译后端

```bash
cd server
go build -o server main.go
```

### 2. 配置 API Key

**两种配置方式**：

#### 方式一：配置文件（推荐）
```bash
cd server
cp .env.example .env
# 编辑 .env 文件，填入你的 OPENAI_API_KEY
```

#### 方式二：环境变量
```bash
export OPENAI_API_KEY=your-openai-api-key-here
```

> 如果你没有 API Key，直接启动也能运行，会返回模拟数据供前端调试

### 3. 启动服务

```bash
./server
```

服务默认监听 `http://localhost:8081`

## 前端使用

### Web 端

#### 构建

```bash
flutter pub get
flutter build web --release
# 把 build/web 部署到你的 Web 服务器
```

#### 使用流程

1. **搜索模式**
   - 打开网页，输入你想学习的问题，点击「搜索」
   - 得到核心答案，蓝色带下划线的是自动提取的关键词
   - **点击关键词** → 弹出弹窗显示详细解释
   - **长按文本** → 添加**自定义关键词** → 输入标注说明（比如"我想了解它在前端的应用"）→ 获取解释
   - 解释获取完后，点击「生成完整学习文档」→ 自动切换到**学习模式**

2. **学习模式**
   - 顶部展示思维导图（Markdown 缩进格式）
   - 下方是完整结构化学习文档
   - **长按文档任意位置** → 同样可以添加自定义关键词解释
   - 点击「导出 Markdown」/「导出 PDF」→ 浏览器开始下载

3. **重新搜索**
   - 学习模式点击 AppBar 右上角刷新图标 → 返回搜索模式清空内容

## 功能详解

### 自动关键词 vs 自定义标注

| 类型 | 触发方式 | 说明 |
|------|---------|------|
| 自动关键词 | 点击蓝色关键词 | LLM 自动提取的核心知识点，点击查看解释 |
| 自定义标注 | 长按文本 | LLM 不知道用户关心什么，用户自己选文本添加个性化标注 |

### 自定义标注使用场景

- 自动提取的关键词没覆盖到你关心的内容
- 你对某个概念有特定角度想了解，可以添加标注说明（比如 "请结合鸿蒙开发讲解"）
- 你知道哪里不懂，直接选中文本让 AI 解释

## 常见问题

**Q: 提示 "导出失败"**  
A: 检查后端服务是否正常启动，网络是否连通

**Q: 为什么长按不是直接选中文本而是要手动输入？**  
A: Flutter Web 文本选中获取在跨端框架中比较复杂，MVP 采用简化方案：长按弹出对话框手动输入，体验足够好且实现简单

**Q: 支持其他 LLM 吗？**  
A: 后端采用 OpenAI 兼容接口，只要是兼容 OpenAI API 格式的 LLM 服务都可以用，修改 baseURL 即可
